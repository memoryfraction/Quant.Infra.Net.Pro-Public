MCP

Use Quant.Infra.Net.Pro with AI clients

Read-only access for Claude Code, Cursor and other MCP clients.

MCP

v1.8.4+

Let an AI client read your Schwab data. Read-only and off by default.

  • What it is. Quant.Infra.Net.Pro can let AI clients such as Claude Code or Cursor read your account, positions, orders, quotes and option chains through MCP (Model Context Protocol). It runs inside the app on your own computer at https://127.0.0.1:8443/mcp. It cannot place, change or cancel any order. Available from v1.8.4.
  • 1. Turn it on. Open your settings file and add the block below, then restart the app. Windows: %APPDATA%\Quant.Infra.Net.Pro\config\appsettings.user.json. macOS and Linux: ~/.config/Quant.Infra.Net.Pro/config/appsettings.user.json. Merge it into the existing JSON instead of creating a second top-level object.

{ "Mcp": { "Enabled": true } }

  • 2. Get your token. On first start the app creates mcp-token.txt in the same config folder. Every request must send it as Authorization: Bearer <token>. Treat the token like a password and never share it. To replace it, stop the app, delete the file and start the app again.
  • 3. Connect Claude Code. Run the command below with your token. Other clients need the same three things: the URL, the HTTP (Streamable HTTP) transport and the Authorization header; see their own MCP documentation.

claude mcp add --transport http quant-infra https://127.0.0.1:8443/mcp --header "Authorization: Bearer <token>"

  • 4. If the client complains about the certificate. The app uses its own local certificate authority. Trust the file certs/quant-ca.cer in your data folder. For Node-based clients set NODE_EXTRA_CA_CERTS to that file's path.
  • Tools (all read-only). get_account, get_balances, get_positions, get_orders, get_order, get_quote, get_quotes, get_price_history, get_option_chain, calculate_rebalance. calculate_rebalance only suggests; trading is done in the app.
  • Privacy. Everything a tool returns is sent to the AI service your client uses. Only turn MCP on if you are comfortable with that service seeing your account, positions, orders and quotes. To turn it off, set Enabled to false and restart.
