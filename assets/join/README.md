# `assets/join/` — 二维码图片替换说明

`/join/` 页面用到两张图。**现在这两张是占位图**（图上有红条写着「占位：请替换为真实二维码」），不是可用二维码，扫不出来。上线前必须换成真实的。

| 文件 | 用途 | 页面位置 |
|---|---|---|
| `official.png` | 公众号二维码 | `/join/` 左侧「关注公众号」 |
| `group.png` | 微信群活码/群二维码 | `/join/` 右侧「进微信群」 |

## 怎么换

1. 把真实二维码图片，按下面的文件名覆盖到 `assets/join/`：
   - 公众号 → `official.png`
   - 微信群 → `group.png`
2. 建议规格：**正方形，建议 900×900 或以上**（页面里最大显示 280px，留 2× 以上余量给高分屏）；PNG；二维码四周**留白边（静默区）**，不要贴边裁切，否则扫不出来。
3. 提交后记得**刷新 Cloudflare 缓存**（图片是静态资源，缓存 4 小时）。如果文件名没变而内容变了，也可以改名（如 `official-2026q4.png`）并同步改 `/join/index.html` 里的 `src`，能立刻绕过缓存。
4. 重新生成占位图（一般用不上）：`python scripts/make-join-placeholders.py`。

## 重要：群二维码有 7 天有效期

微信**群二维码只有 7 天有效**（官方限制，到期自动失效）。所以：

- **不要**把群二维码当长期方案。7 天换一次，很容易忘，忘了就是一片扫不进来的死链。
- **推荐做法：用企业微信「客户群活码」**（也叫群活码/自动建群码）。它的图是**固定的**，用户扫码后由企业微信自动分配进群、群满了自动开新群，长期不用换图。这是解决 7 天过期问题的标准做法。
  - 前提是要有一个企业微信主体（个人可注册企业微信，用个人身份也能建客户群）。
  - 建成后把活码图片导出，覆盖 `group.png` 即可，**以后基本不用再动**。
- **退路（页面已经写好）**：`/join/` 上有提示「二维码过期了？发邮件到 alphawealthlab@outlook.com，我们会拉你进群」，所以即使二维码失效也不会把人彻底卡死。请确保这个邮箱是你在看的邮箱。

公众号二维码是**长期有效**的，不用定期更换。

## 别忘了

- `/join/` 页面已在 `<head>` 里设了 `<meta name="robots" content="noindex,nofollow">`，`robots.txt` 里有 `Disallow: /join/`，`sitemap.xml` **不收录**该页 —— 都是刻意为之（微信二维码不适合被搜索引擎长期缓存）。**换图时不要顺手改这几处。**
