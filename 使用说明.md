## 1. 简介 / Introduction

### English

**Quant.Infra.Net.Pro** is a local web application that provides an unattended trading gateway for Charles Schwab brokerage accounts. It runs entirely on your own machine, with no cloud intermediaries and no data leaving your computer.

The core problem it solves: Schwab API tokens expire frequently (access token: 30 min, refresh token: 7 days), making 24/7 automated trading impossible without constant manual intervention. This application automates the entire token lifecycle, handles OAuth re-authorization, MFA recovery, and SSL certificate management — all without user interaction.

### 中文

**Quant.Infra.Net.Pro** 是一款本地运行的 Web 应用，为 Charles Schwab（嘉信理财）交易账户提供无人值守的交易网关。它完全运行在您自己的电脑上，没有云中间商，数据不离开您的计算机。

它解决的核心问题：Schwab API Token 过期频繁（Access Token 30 分钟，Refresh Token 7 天），如果没有持续的手动干预，7×24 自动化交易几乎不可能。该应用自动化了整个 Token 生命周期，自动处理 OAuth 重授权、MFA 恢复和 SSL 证书管理——全程无需用户操作。

## 2. 快速入门 / Quick Start

### English

**Step 1: Download**

Download the ZIP package for your operating system from GitHub Releases: https://github.com/memoryfraction/Quant.Infra.Net.Pro-Public/releases

**Step 2: Extract**

Unzip to any folder (e.g., C:\\QuantPro\\).

**Step 3: Run**

- Windows: double-click Quant.Infra.Net.Pro.Web.exe
- macOS/Linux: run ./Quant.Infra.Net.Pro.Web in terminal

On first launch, the app will:
1. Generate a self-signed HTTPS certificate (5-year validity)
2. Start the web server on https://127.0.0.1:8443
3. Show startup log in the console

**Step 4: Open browser**

Navigate to https://127.0.0.1:8443.

> A security warning will appear — this is expected. Click Advanced -> Proceed to 127.0.0.1.

**Step 5: Activate and configure**

Follow the on-screen /start flow (see Section 3 below).

### 中文

**第一步：下载**

从 GitHub Releases 下载对应操作系统的 ZIP 包。

**第二步：解压**

解压到任意文件夹（如 C:\\QuantPro\\）。

**第三步：运行**

- Windows：双击 Quant.Infra.Net.Pro.Web.exe
- macOS/Linux：在终端中运行 ./Quant.Infra.Net.Pro.Web

首次启动时，应用会自动：
1. 生成自签名 HTTPS 证书（5 年有效）
2. 在 https://127.0.0.1:8443 上启动 Web 服务器
3. 在控制台打印启动日志

**第四步：打开浏览器**

在浏览器中访问 https://127.0.0.1:8443。

> 会出现安全警告——这是正常现象。点击高级->继续前往。

**第五步：激活与配置**

按照 /start 页面的指引操作（详见第 3 节）。

## 3. 授权激活 / License Activation

### English

### New Users

The activation flow protects both you and us:

1. **Open /start** — Enter your email address
2. **Verify Email** — Click "Send Verification Link". Check your inbox (and spam folder) for a verification email. Click the link in the email, then return to /start and click "Verify Email" again
3. **Choose your path**:
   - **7-Day Free Trial**: Activate immediately — full functionality for 7 days
   - **I Have a License**: Enter your purchased license key manually
4. **License Auto-Saved** — On success, the app saves the License Key and Email to local appsettings.json
5. **Proceed to /settings** — Enter your Schwab API credentials

**Important security policy:**
- The app never reveals a license key by email lookup
- The verification email link is single-use and expires

### Existing Users

- Go directly to **/settings** and enter your License Key and Email manually
- No need to go through /start

### Free Trial

- 7 days, full functionality, 1 device
- One trial per email per product — even after expiry, no new trial can be created
- Email verification is required before activating

### License Renewal

- When your license expires, visit the purchase link to renew
- After successful LemonSqueezy payment, the license is automatically extended
- If already expired: extended by 30 days from payment time
- If still active: extended by 30 days from current expiry date

### 中文

### 新用户

激活流程保护双方的利益：

1. 打开 /start 输入您的邮箱地址
2. 验证邮箱: 点击"发送验证链接"。检查收件箱和垃圾邮件文件夹，点击验证链接，返回 /start 再次点击"验证邮箱"
3. 选择路径：
   - 7 天免费试用：立即激活
   - 我有 License：手动输入购买获得的授权码
4. 自动保存：激活成功后，应用将 License Key 和 Email 自动保存到本地 appsettings.json
5. 前往 /settings 输入您的 Schwab API 凭据

**重要安全策略：**
- 应用不会通过邮箱查询来显示 License Key
- 验证链接一次性使用，过期作废

### 已有用户

- 直接前往 /settings 手动输入 License Key 和 Email
- 无需经过 /start 流程

### 免费试用

- 7 天，全部功能，1 台设备
- 同一产品同一邮箱仅可领取一次
- 试用前必须完成邮箱验证

### 续费

- License 过期后前往 /settings 页面点击购买链接续费
- 通过 LemonSqueezy 付款成功后，License 自动延长
- 已过期：从付款时间延长 30 天
- 未过期：从当前过期时间延长 30 天

## 4. 初始配置 / Initial Configuration

### English

After activation, go to **/settings**:

| Field | Required | Description |
|-------|----------|-------------|
| License Key | Yes | Your license key (QIF-xxxx format) |
| Email | Yes | The email associated with your license |
| Schwab App Key | Yes | Your Schwab API Client ID |
| Schwab App Secret | Yes | Your Schwab API Client Secret |
| Schwab Account Number | Yes | Your Schwab account number |
| Redirect URI | No | Default: https://127.0.0.1:8443/signin-oidc |

## 7. 无人值守运行 / Unattended Operation

### English

| Challenge | Solution | Duration |
|-----------|----------|----------|
| Access token expires every 30 min | Background refresh every 15 min | Unlimited |
| Refresh token expires every 7 days | Playwright re-auth on day 6.5, 30-hour retry window | Unlimited |
| MFA challenge | Dashboard banner + manual recovery | User handles |
| SSL cert expires | Auto-renewed when less than 30 days remaining | 5 years |
| Network disruption | Polly exponential backoff retry | Auto-recovery |

### 中文

| 挑战 | 方案 | 时长 |
|------|------|------|
| Access Token 30 分钟过期 | 后台每 15 分钟刷新 | 无限制 |
| Refresh Token 7 天过期 | Playwright 第 6.5 天自动重授权 | 无限制 |
| MFA 挑战 | 仪表盘横幅 + 手动恢复 | 用户处理 |
| SSL 证书到期 | 到期前 30 天自动续期 | 5 年 |
| 网络中断 | Polly 指数退避重试 | 自动恢复 |
